# Tianyang Chen — GIS Scientist

Personal academic website and research portfolio for Tianyang Chen, Ph.D.

The site presents research in spatially grounded GeoAI, 3D geospatial intelligence, scalable spatial systems, selected publications, interactive geospatial work, and teaching and mentoring.

## Highlights

- Interactive rotating world map
- Procedural LiDAR bridge point-cloud visualization
- Research trajectory: Measure → Model → Learn → Reason
- TerraWatch, DeepPipe, and Geo-FRIT project features
- Selected publications and teaching philosophy
- Responsive layout and reduced-motion support

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
